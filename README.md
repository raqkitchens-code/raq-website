# راق — الموقع الرسمي

موقع عربي ثابت باتجاه RTL لراق، مبني من HTML وCSS وJavaScript دون خادم أو اعتماديات خارجية.

## التطوير والتحقق

افتح `index.html` مباشرة أو شغّل خادم ملفات ثابتة من جذر المشروع. يتطلب فحص الموقع Node.js:

```sh
node scripts/check-site.mjs
```

مسار `/plan` يستضيف مخطط المطابخ في وضع الاستخدام الذاتي (Self). نسخة الموقع الحالية مبنية من `raqkitchens-code/KITCHEN-PLANNER` عند SHA المسجل في `plan/version.json`. ومسارات `/qr/showroom` و`/qr/flyer` و`/qr/card` تعيد الزائر إلى الموقع مع قيمة `src` فقط.

تستخدم الصفحة صور التصور البصري الجاهزة للنشر، وتحتوي بطاقات الخدمات على خانات للصور المعتمدة التي ستضاف لاحقًا. راجع `assets/products/README.md` لأسماء الصور المقترحة.

ملفات تسليم RAQ، ومراجع العمل الداخلية، والأرشيف الخام للصور مستبعدة من مستودع الموقع العام عبر `.gitignore`.
